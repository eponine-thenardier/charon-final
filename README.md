# Charon

Watch the demo [here](https://youtu.be/fq1fW19cW8Q).

Charon is a travel planning web application that combines weather forecasts and personalized attraction recommendations to help users plan their vacations efficiently. Developed using React (JavaScript), HTML, CSS, and the OpenAI API, Charon is designed to be an intelligent and user-friendly travel assistant.


## Features

- **Weather Forecasts**: Get up-to-date weather information for your selected destination.
- **Top Attractions**: View a curated list of the top 5 nearby attractions based on your preferences and location.
- **Modern UI/UX Design**: Created with Figma and implemented using modern design principles for an intuitive and visually appealing interface.
- **Task Management**: Developed and managed using Agile methodologies with a SCRUM board to ensure timely completion.
- **Demo Video**: Features an engaging project presentation showcasing Charon’s functionality and user interface.

## Technologies Used

- **Frontend**: React (JavaScript), HTML, CSS
- **API Integration**: OpenAI API for personalized travel recommendations
- **Design Tools**: Figma for UI/UX design
- **Agile Methodologies**: SCRUM board for task management

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/username/charon.git
   ```
2. Navigate to the project directory:
   ```bash
   cd charon
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a `.env` file in the root directory and add your OpenAI API key:
   ```
   REACT_APP_OPENAI_API_KEY=your_api_key_here
   ```
5. Start the development server:
   ```bash
   npm start
   ```
6. Open your browser and navigate to `http://localhost:3000` to use Charon.

## Usage
Explore Charon live at: [Charon Web App](https://charon-final-n2ui.vercel.app/)

1. Enter your desired travel destination.
2. View the weather forecast for your selected location.
3. Explore the top 5 attractions Charon recommends in your chosen location.
